# CloudBar — Telegram Mini App для вейп-шопа

Полнофункциональный интернет-магазин в формате Telegram Mini App: каталог,
корзина, оформление заказа, история заказов, избранное, профиль с бонусами
— и встроенная **админ-панель** (без отдельного веб-кабинета) для управления
товарами, заказами, категориями, промокодами, клиентами и настройками магазина.

## Стек

- **Клиент**: React 18 + TypeScript + Vite, React Router, Zustand (корзина/избранное/сессия),
  Framer Motion, Recharts (графики в админке), Telegram WebApp SDK.
- **Сервер**: Node.js + Express + better-sqlite3 (файловая БД, без внешних зависимостей).
- **Бот**: grammy — команда `/start` открывает мини-апп, `/admin` открывает
  панель управления, сервер уведомляет админов о новых заказах.

## Структура проекта

```
server/   REST API + Telegram-бот + SQLite
client/   React-приложение (витрина + админ-панель)
```

## Быстрый старт (локально)

```bash
npm install --workspaces

# сервер
cp server/.env.example server/.env
# впишите BOT_TOKEN и свой Telegram ID в ADMIN_IDS в server/.env
npm run seed --workspace server   # заполнить БД демо-данными
npm run dev:server                # http://localhost:8787

# клиент (в отдельном терминале)
npm run dev:client                # http://localhost:5173
```

Для разработки вне Telegram клиент подставляет мок `window.Telegram.WebApp`
(см. `client/src/lib/telegram.ts`). Откройте `http://localhost:5173/?mock=admin`,
чтобы увидеть приложение от лица администратора (id из `ADMIN_IDS`), или без
параметра — от лица обычного покупателя.

## Продакшн

1. Разверните `server` (Express-приложение) на любом Node-хостинге, добавьте
   `BOT_TOKEN`, `ADMIN_IDS`, `WEBAPP_URL` в переменные окружения.
2. Соберите клиент: `npm run build --workspace client` → раздайте `client/dist`
   как статику по HTTPS (тот же домен или отдельный, главное — HTTPS).
3. У @BotFather выполните `/setmenubutton` или `/newapp`, укажите URL клиента.
4. Запустите бота: `npm run bot --workspace server` (long polling) или разверните
   как webhook.

## Основной функционал

**Витрина**: возрастной гейт 18+, главная с промо-баннером и категориями,
каталог с поиском/сортировкой/фильтрами, карточка товара с выбором крепости
никотина и количества, корзина, оформление заказа (доставка/самовывоз,
оплата картой/наличными, промокоды), история заказов со статус-трекером,
избранное, профиль с бонусным счётом.

**Админ-панель** (доступна пользователям из `ADMIN_IDS`, прямо внутри мини-аппа):
дашборд с выручкой/графиками/топ-товарами, CRUD товаров и категорий,
управление заказами со сменой статусов, промокоды, база клиентов
(блокировка), настройки магазина (доставка, оплата, контакты).
